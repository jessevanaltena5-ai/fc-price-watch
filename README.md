# FC Price Watch

Tampermonkey-userscripts voor de EA FC Ultimate Team web app.

| Script | Wat |
| --- | --- |
| [price-watch.user.js](price-watch.user.js) | **FC Price Watch** – eigen tab met FUT Genie-prijzen, doelprijzen, stock-/snipe-/fodderlijsten en sync met je telefoon. |
| [pt-transfermarkt-knop.user.js](pt-transfermarkt-knop.user.js) | Oud: 🔍-knop in de Paletools Price Tracker. |
| [price-tracker-plus.user.js](price-tracker-plus.user.js) | Oud: Price Tracker Plus voor de Paletools-tabel. |

## Installeren

1. Installeer [Tampermonkey](https://www.tampermonkey.net/).
2. Open de **raw**-link van het script, bijvoorbeeld
   <https://raw.githubusercontent.com/jessevanaltena5-ai/fc-price-watch/main/price-watch.user.js>
3. Tampermonkey toont het installatiescherm → **Installeren**.

FC Price Watch werkt zichzelf daarna bij vanaf deze repo (Tampermonkey → Updates zoeken).

## Live via je pc (optioneel)

Je GitHub-token en gist staan **niet** in deze repo. Vul ze zelf in onder *⇄ Overzetten → Live via je pc*;
ze blijven alleen in Tampermonkey op je eigen apparaat.
